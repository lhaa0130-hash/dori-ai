<h2 id="sec-3">2. 움직임</h2>
<p>가장 공들인 부분.</p>
<p><strong>걸을 때</strong> — 8프레임 순환. 발이 땅에 닿을 때마다 먼지가 인다
<strong>서 있을 때</strong> — 숨을 쉰다
<strong>벨 때</strong> — 뒤로 젖혔다가 앞으로 내디디며 내리친다. 병기가 팔을 따라 크게 돈다
<strong>구를 때</strong> — 몸을 말고 낮아진다</p>
<p>몬스터도 걷고, 덤빌 때 몸을 젖혔다 튕긴다. 마을 사람들도 걸을 때 통통 뜬다.</p>
<p><strong>공격은 단일 타격.</strong> 부채꼴로 쓸던 것을 겨눈 적에게 곧게 뻗는 초승달 참격으로 바꿨다. 붙어 선 셋 중 하나만 맞는다.</p>
<hr>
<h2 id="sec-4">3. 처음 십단까지</h2>
<p>촌장의 심부름 사슬로 다시 짰다.</p>
<pre><code>내 집 앞에서 시작
 수련1  촌장께 인사              → 2단
 수련2  대장장이에게 보따리       → 목검 · 3단
 수련3  갑옷장이에게 쇠붙이       → 무명옷 · 4단
 수련4  촌장께 보고              → 5단
 수련5  수련법·승단 설명          → 베기 해금
 수련6  십단에 촌장 방문          → 구르기 · 마을문 개방 · 1차 전직
</code></pre>
<p><strong>1~5단은 공격할 수 없다.</strong> 촌장이 가르쳐 줘야 벨 수 있다.
<strong>허수아비 44대</strong>면 5단에서 10단이 된다(약 60초).</p>
<p>십단 뒤 첫 사냥터는 <strong>개미벌판</strong>. 개미굴과 여왕이 있고, 처음 나서면 촌장의 목소리가 들린다.</p>
<hr>
<h2 id="sec-5">4. 전직 — 오차 16갈래</h2>
<pre><code>살아있는자
├ 무인의 길 — 짐승을 베어 공력을 쌓는다
│  무문 문하생 → 발도 무사 → 성명 무사
│   ├ 검성  → 협검존(정) / 혈검마(사)
│   ├ 권왕  → 금강권성(정) / 파천권마(사)
│   ├ 궁신  → 백보신궁(정) / 암궁살수(사)
│   └ 도제  → 정도도존(정) / 폭혈도귀(사)
└ 장인의 길 — 캐고 벼려서 공력을 쌓는다
   공방 문도 → 숙련 공장 → 명장
    ├ 도공   → 신병조사(정) / 마병주조(사)
    ├ 약왕   → 활인의선(정) / 만독지체(사)
    ├ 기관사 → 천기공사(정) / 흉기괴사(사)
    └ 부적사 → 호신부사(정) / 저주부사(사)
</code></pre>
<p><strong>전직 단수 10 / 50 / 100 / 150 / 200</strong></p>
<p>정파는 지키고 사파는 벤다. 금강권성은 체력 +320, 파천권마는 공격 +42.
사파를 고르면 전직 연출이 <strong>붉게</strong> 물든다.</p>
<hr>
<h2 id="sec-6">5. 장인의 길</h2>
<p>무인은 짐승을 베지만 장인은 캐고 벼린다. <strong>장인은 사냥으로 공력이 오르지 않는다</strong> — 코드로 막아뒀다.</p>
<p><strong>채집</strong> — 지역마다 나는 것이 다르다. 약초·무쇠광·단단목·무두질가죽·옥돌. 1.3초 걸리고 25초 뒤 다시 난다
<strong>공방</strong> — 마을 서쪽. 화덕에 불이 일렁인다. 일곱 가지를 벼릴 수 있고, <strong>장인이 만들면 등급이 훨씬 잘 나온다</strong></p>
<hr>
<h2 id="sec-7">6. 경지 — 단수와 무관하다</h2>
<pre><code>무명 → 삼류 → 이류 → 일류 → 절정 → 초절정 → 화경 → 현경 → 생사경
</code></pre>
<p>단수가 아니라 **벤 수와 닦은 몸(스탯)**으로 오른다. 삼류는 40처치 + 스탯 8. 50단쯤이면 일류까지 갈 수 있다.</p>
<p>돌파하면 푸른 물결이 퍼지는 연출이 나온다.</p>

<pre><code>동  개미벌판10 → 벌집골14 → 들개마루18 → 대숲22 → 멧돼지수풀26
남  토끼둔덕10

<p>마지막은 <strong>구천현제(200단)</strong>. 문 앞에 권장 단수가 붙고, 너무 위험하면 「죽음이 기다리오」가 뜬다.</p>
<p><strong>경험 최대 8,400 · 피해 최대 124.</strong> 숫자가 부풀지 않게 계속 눌러 왔다.</p>

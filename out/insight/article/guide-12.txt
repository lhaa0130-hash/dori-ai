15:T2b8a,<h2>1. 무료 AI는 세 가지 유형으로 나뉜다</h2>
<p>한도가 "얼마나 주느냐"보다 **"어떤 방식으로 주느냐"**가 실사용에서 훨씬 중요합니다.</p>
<h3>유형 A — 사실상 무제한형</h3>
<p>한도를 거의 신경 쓰지 않고 쓸 수 있는 쪽입니다.</p>
<ul>
<li><strong>DeepSeek</strong> — 웹 채팅에 사실상 사용 한도가 없습니다. 수학·코딩 추론이 유료 모델급입니다</li>
<li><strong>Google AI Studio</strong> — 하루 요청 한도가 무료 서비스 중 가장 넉넉하고, <strong>무료 API 키까지 발급</strong>됩니다</li>
<li><strong>Perplexity</strong> — 기본 검색은 거의 무제한이고, 고급 검색만 하루 몇 회로 제한됩니다</li>
</ul>
<p>이 셋은 "한도 걱정 없이 일단 던져보는" 용도로 씁니다.</p>
<h3>유형 B — 한도형 (리셋 주기가 관건)</h3>
<p>최신 모델을 정해진 양만큼 주는 쪽입니다. <strong>중요한 건 총량이 아니라 리셋 주기입니다.</strong></p>
<ul>
<li><strong>ChatGPT 무료</strong> — 최신 모델을 하루 정해진 횟수까지. 한도를 다 써도 <strong>경량 모델로 자동 전환돼 대화가 끊기지 않습니다</strong></li>
<li><strong>Claude 무료</strong> — 한도가 하루 단위가 아니라 <strong>몇 시간 주기로 다시 채워집니다.</strong> 몰아 쓰면 금방 소진되지만, 나눠 쓰면 하루 종일 쓸 수 있습니다</li>
</ul>
<p>이 차이가 실사용에서 큽니다. Claude는 "오전에 한 번, 오후에 한 번" 식으로 쓰면 유료 없이도 꽤 버팁니다. 반대로 한 번에 몰아 쓰면 30분 만에 막힙니다.</p>
<h3>유형 C — 기능 제한형</h3>
<p>쓸 수는 있는데 <strong>속도나 기능에 차등</strong>을 두는 쪽입니다.</p>
<ul>
<li><strong>Microsoft Copilot</strong> — 이미지 생성에 하루치 고속 크레딧을 주고, 다 쓰면 <strong>속도만 느려질 뿐 계속 생성됩니다</strong></li>
<li><strong>Canva Magic Studio</strong> — 디자인 도구 안에서 AI 기능을 일정량 제공합니다</li>
<li><strong>Leonardo.Ai</strong> — 이미지 생성에 하루 크레딧이 충전됩니다</li>
</ul>
<p>"막히는" 게 아니라 "느려지는" 구조라, 급하지 않으면 계속 쓸 수 있습니다.</p>

<p>전체 목록과 각 도구의 장단점은 <a href="/ai-tools">AI 도구 모음</a>에서 볼 수 있습니다.</p>
<h3>고르기 전에 알아둘 단점</h3>
<p>무료 AI 추천 글은 장점만 나열하는 경우가 많습니다. <strong>실제로 쓰다 보면 걸리는 지점</strong>을 함께 적어 둡니다.</p>

<hr>
<h2>3. 무료로 하루를 버티는 실전 조합</h2>
<p>한도에 걸려도 작업이 안 끊기게 하는 방법은 <strong>리셋 주기가 다른 도구를 섞는 것</strong>입니다.</p>
<p><strong>아침 — 무거운 작업 먼저</strong>
Claude로 긴 문서 검토나 보고서 초안을 잡습니다. 한도가 가장 아까운 작업을 가장 좋은 모델에 먼저 씁니다.</p>
<p><strong>낮 — 한도 없는 쪽으로 이동</strong>
Claude 한도가 줄어들면 DeepSeek(코딩·계산)과 Perplexity(자료 조사)로 옮깁니다. 둘 다 한도 걱정이 거의 없습니다.</p>
<p><strong>오후 — Claude 한도 리셋</strong>
몇 시간이 지나면 Claude 한도가 다시 채워집니다. 아침에 잡아둔 초안을 다듬습니다.</p>
<p><strong>아무 때나 — 잡무는 ChatGPT 무료</strong>
파일 정리, 번역, 간단한 질문은 ChatGPT 무료로 넘깁니다. 한도를 넘겨도 경량 모델로 계속 돌아가니 막히지 않습니다.</p>
<p>이 정도만 나눠도 개인 작업은 대부분 유료 없이 굴러갑니다.</p>
<hr>
<h2>4. 무료의 진짜 비용 — 알고 쓰세요</h2>
<p>공짜라고 대가가 없는 건 아닙니다. <strong>돈이 아닌 것으로 냅니다.</strong></p>
<h3>① 입력한 내용이 학습에 쓰일 수 있습니다</h3>
<p>무료 등급에서는 대화 내용이 모델 개선에 사용될 수 있습니다. Google AI Studio 무료 등급도 마찬가지입니다.</p>
<p>→ <strong>회사 내부 문서, 고객 정보, 미공개 코드는 넣지 마세요.</strong> 이건 요금제 문제가 아니라 원칙입니다.</p>
<h3>② 데이터가 어디에 저장되는지 다릅니다</h3>
<p>DeepSeek은 성능이 좋고 무료지만 <strong>데이터가 중국 서버에 저장됩니다.</strong> 개인 학습용으로는 훌륭하지만 업무 자료에는 부적합합니다. 정치·역사 등 일부 주제에는 답변 제약도 있습니다.</p>
<p>→ 무료 AI를 고를 때 성능만 보지 말고 <strong>어디에 저장되는지</strong>를 함께 보세요.</p>
<h3>③ 한도를 예측할 수 없습니다</h3>
<p>무료 한도는 공지 없이 바뀝니다. 어제 되던 게 오늘 안 될 수 있습니다.</p>
<p>→ 마감이 걸린 작업을 무료 한도에 의존하지 마세요. 그때가 유료를 쓸 때입니다.</p>
<hr>
<h2>5. 그럼 언제 돈을 내야 하나</h2>
<p>유료로 넘어갈 시점은 사용량이 아니라 <strong>성격</strong>으로 판단하는 게 정확합니다.</p>
<p><strong>아직 무료로 버텨도 되는 경우</strong></p>
<ul>
<li>하루 몇 번씩 산발적으로 씁니다</li>
<li>막히면 다른 도구로 옮겨도 괜찮습니다</li>
<li>다루는 내용이 공개돼도 상관없습니다</li>
</ul>
<p><strong>유료로 넘어갈 때</strong></p>
<ul>
<li><strong>마감이 걸립니다.</strong> 한도에 막혀 멈추는 비용이 구독료보다 큽니다</li>
<li><strong>민감한 자료를 다룹니다.</strong> 유료 등급은 대체로 학습 제외 옵션이 있습니다</li>
<li><strong>서비스에 AI를 붙입니다.</strong> 이건 구독이 아니라 <strong>API 종량 과금</strong>의 영역입니다</li>
</ul>
<p>마지막 경우가 중요합니다. 챗봇이나 자동화를 만들어 사용자에게 제공하려면 월 구독이 아니라 <strong>쓴 만큼 내는 API 요금</strong>을 계산해야 합니다. 그 구조는 <a href="/insight/article/guide-11">AI API 요금 구조 완전 해부</a>에 정리해 뒀고, 실제 금액은 <a href="/ai-models">AI 모델 가격 비교 · 비용 계산기</a>에서 바로 계산할 수 있습니다.</p>
<p>의외로 저렴합니다. 소규모 서비스라면 <strong>월 몇 달러 수준</strong>에서 시작하는 경우가 많습니다.</p>
<hr>
<h2>마무리</h2>
<p>정리하면 이렇습니다.</p>
<ul>
<li>무료 AI는 <strong>사실상 무제한형 / 한도형 / 기능 제한형</strong> 셋으로 나뉩니다</li>
<li><strong>총량보다 리셋 주기가 중요합니다.</strong> Claude는 몇 시간마다 채워지고, ChatGPT는 한도 후에도 경량 모델로 이어집니다</li>
<li><strong>하나만 쓰지 말고 일마다 나누세요.</strong> 글은 Claude, 검색은 Perplexity, 코딩은 DeepSeek</li>
<li>공짜의 대가는 <strong>데이터</strong>입니다. 민감한 자료는 넣지 마세요</li>
<li>유료 전환은 사용량이 아니라 <strong>마감·민감도·서비스화</strong> 여부로 판단합니다</li>
</ul>
<p>무엇부터 써볼지 모르겠다면 <strong>Google AI Studio</strong>부터 열어보세요. 한도가 가장 넉넉하고 무료 API 키까지 나옵니다.</p>

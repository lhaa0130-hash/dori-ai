1. 그림이 들어왔다

코드로 도형을 그리던 것에서 벗어났다. 전부 gpt-image로 만들고 tools/의 파이썬 도구로 심었다.

캐릭터

  • 다람검객 — 남색 전복에 금색 선, 청록 띠, 노리개
  • 걸음 8프레임 — 한 장에 4×2 격자로 뽑아야 그림이 서로 맞는다. 따로 뽑으면 안 맞는다
  • 병기 6종 — 몸은 빈손으로 그리고 칼만 손에 얹는다. 걸음 8칸마다 손 위치와 각도를 따로 잡았다

몬스터 — 왕개미, 들쥐, 개미굴 여왕 사람 — 촌장 백호(호랑이), 대장장이 무쇠(멧돼지), 갑옷장이 두칠(너구리) 바닥 — 풀밭·마른땅·눈 세 종류. 21개 지역이 셋을 나눠 쓰되 물들이는 정도가 달라 서로 달라 보인다 건물 — 초가집·농가·기와집·대장간·주막·곳간 여섯 동 첫 화면 — 청풍마을 아침 풍경

배운 것

  • 한 장에 격자로 뽑아야 한다. 프레임을 따로 생성하면 옷도 얼굴도 매번 달라진다
  • 자를 때 공통 테두리를 써야 한다. 칸마다 따로 자르면 몸이 뜨는 움직임이 지워져 제자리걸음이 된다
  • 바닥 무늬에 색이 있으면 지역 색을 끌고 간다. 처음엔 눈밭이 초록이 됐다. 색을 빼고 회색 결만 남겼다가, 결국 지형별로 따로 그렸다
  • 옷을 레이어로 입히는 건 AI 생성으로는 안 된다. 테일즈위버처럼 한 벌 통째로, 병기만 분리

2. 움직임

가장 공들인 부분.

걸을 때 — 8프레임 순환. 발이 땅에 닿을 때마다 먼지가 인다 서 있을 때 — 숨을 쉰다 벨 때 — 뒤로 젖혔다가 앞으로 내디디며 내리친다. 병기가 팔을 따라 크게 돈다 구를 때 — 몸을 말고 낮아진다

몬스터도 걷고, 덤빌 때 몸을 젖혔다 튕긴다. 마을 사람들도 걸을 때 통통 뜬다.

공격은 단일 타격. 부채꼴로 쓸던 것을 겨눈 적에게 곧게 뻗는 초승달 참격으로 바꿨다. 붙어 선 셋 중 하나만 맞는다.

3. 처음 십단까지

촌장의 심부름 사슬로 다시 짰다.

내 집 앞에서 시작
 수련1  촌장께 인사              → 2단
 수련2  대장장이에게 보따리       → 목검 · 3단
 수련3  갑옷장이에게 쇠붙이       → 무명옷 · 4단
 수련4  촌장께 보고              → 5단
 수련5  수련법·승단 설명          → 베기 해금
 수련6  십단에 촌장 방문          → 구르기 · 마을문 개방 · 1차 전직

1~5단은 공격할 수 없다. 촌장이 가르쳐 줘야 벨 수 있다. 허수아비 44대면 5단에서 10단이 된다(약 60초).

십단 뒤 첫 사냥터는 개미벌판. 개미굴과 여왕이 있고, 처음 나서면 촌장의 목소리가 들린다.

4. 전직 — 오차 16갈래

살아있는자
├ 무인의 길 — 짐승을 베어 공력을 쌓는다
│  무문 문하생 → 발도 무사 → 성명 무사
│   ├ 검성  → 협검존(정) / 혈검마(사)
│   ├ 권왕  → 금강권성(정) / 파천권마(사)
│   ├ 궁신  → 백보신궁(정) / 암궁살수(사)
│   └ 도제  → 정도도존(정) / 폭혈도귀(사)
└ 장인의 길 — 캐고 벼려서 공력을 쌓는다
   공방 문도 → 숙련 공장 → 명장
    ├ 도공   → 신병조사(정) / 마병주조(사)
    ├ 약왕   → 활인의선(정) / 만독지체(사)
    ├ 기관사 → 천기공사(정) / 흉기괴사(사)
    └ 부적사 → 호신부사(정) / 저주부사(사)

전직 단수 10 / 50 / 100 / 150 / 200

정파는 지키고 사파는 벤다. 금강권성은 체력 +320, 파천권마는 공격 +42. 사파를 고르면 전직 연출이 붉게 물든다.

5. 장인의 길

무인은 짐승을 베지만 장인은 캐고 벼린다. 장인은 사냥으로 공력이 오르지 않는다 — 코드로 막아뒀다.

채집 — 지역마다 나는 것이 다르다. 약초·무쇠광·단단목·무두질가죽·옥돌. 1.3초 걸리고 25초 뒤 다시 난다 공방 — 마을 서쪽. 화덕에 불이 일렁인다. 일곱 가지를 벼릴 수 있고, 장인이 만들면 등급이 훨씬 잘 나온다

6. 경지 — 단수와 무관하다

무명 → 삼류 → 이류 → 일류 → 절정 → 초절정 → 화경 → 현경 → 생사경

단수가 아니라 **벤 수와 닦은 몸(스탯)**으로 오른다. 삼류는 40처치 + 스탯 8. 50단쯤이면 일류까지 갈 수 있다.

돌파하면 푸른 물결이 퍼지는 연출이 나온다.

7. 방 (榜)

십단부터 마을 동쪽 방에 관아의 공문이 붙는다. 토벌·소탕·참수 세 가지.

시한 안에 마치되, 빨리 안 죽고 마칠수록 값이 오른다.

등급 조건 값
갑등 (甲) 안 죽고 시한 절반 이상 남기면 2.2배
을등 (乙) 한 번 이하로 죽고 넉넉히 1.5배
병등 (丙) 시한 안에 마치기만 그대로

8. 강호와 그 바깥

사냥터 20곳. 마을에서 네 갈래로 뻗는다.

동  개미벌판10 → 벌집골14 → 들개마루18 → 대숲22 → 멧돼지수풀26
남  토끼둔덕10
북  흑풍산채16 → 설한령24 → 화전터30
서  검은늪30 → 폐사찰34 → 귀곡42
      ↓ 강호 바깥
    만마전46 → 혈사곡62 → 뇌운봉80 → 마교총단100
    → 빙마곡120 → 검총145 → 천마성170 → 구천현궁195

마지막은 구천현제(200단). 문 앞에 권장 단수가 붙고, 너무 위험하면 「죽음이 기다리오」가 뜬다.

경험 최대 8,400 · 피해 최대 124. 숫자가 부풀지 않게 계속 눌러 왔다.

9. 그 밖

  • 자동이동 — 의뢰창에서 누르면 목적지까지 걸어간다. 도착하면 알려준다
  • 특수 자질 — 담·안·운·혼. 엽전으로만 오른다. 살 때마다 값이 55~75% 뛴다. 보통 스탯은 돈으로 못 산다
  • 계정 — dori-ai.com · illo.im 과 같은 아이디 규칙. 지금은 이 기기에만 저장된다
  • 오프닝 5장 — 장면마다 그림이 다르다. 여덟 협객이 하나씩 사라진다
  • 마을 사람 8명 — 자기 집 주변을 돌아다니고 혼잣말을 흘린다. 말 걸려고 다가가면 멈춰 선다

잡은 버그

  • 순간이동 — 튜토리얼 중 문에 닿으면 매 프레임 지도 중앙으로 6%씩 끌려갔다. 첫 프레임에 60px
  • 길잡이가 엉뚱한 곳 — 튜토리얼 중에도 사냥 의뢰를 가리켰다
  • 업적이 안 지워짐 — 새 인물을 만들어도 남아 있었다
  • 맨손인데 칼이 보임 — 무기 없을 때 0번 칸을 그렸다
  • 방이 상점 위에 — 방물장수와 40px 거리라 상점이 먼저 열렸다
  • charset 누락 — 서버 설정에 따라 한글이 깨질 자리였다

# 사이트 연결부 후속 과제 (Workstream 13)

작성: 2026-07-26 · 범위: My World 작업 중 발견했으나 **이 트랙에서 고치지 않은** 사이트 공통 문제.
근거와 우선순위만 기록한다. 홈 리디자인·인증 구조·광고 시스템·상점 계약은 건드리지 않았다.

---

## P0 — My World 가 사실상 도달 불가였다 (이번에 부분 해결)

### 발견

`/my-world` 로 가는 링크가 **사이트 전체에 하나도 없었다.**

```
grep -rn '"/my-world"' app components --include=*.tsx   → 0건 (next=/my-world 리다이렉트 파라미터 제외)
```

헤더 nav(`AI 정보·프로젝트·인사이트·피드·마켓·키즈·놀이터`), 하단 탭바(`홈·인사이트·AI도구·게임·더보기`),
`AccountMenu`, 홈 어디에도 없어 **URL 직접 입력**만이 유일한 경로였다.

### 이번에 한 것 (허용 범위: "My World 진입 링크의 명칭·아이콘·active 상태")

`components/layout/BottomNav.tsx` 의 `MORE_ITEMS` 맨 앞에 한 줄 추가.

```
{ name: "My World", nameEn: "My World", href: "/my-world", emoji: "🏡" }
```

- 모바일 "더보기" 시트에서 도달 가능해진다.
- `hrefEn` 이 없어 영어 모드에서는 자동으로 숨는다(한국어 전용 화면이므로 의도된 동작).
- 전역 nav·헤더·`AccountMenu` 는 건드리지 않았다.

### 남은 것 (제품 결정 필요)

| 우선순위 | 항목 | 근거 |
| --- | --- | --- |
| **P0** | 데스크톱 진입점 | 데스크톱에는 하단 탭바가 없다(`lg:hidden`). 즉 **데스크톱 사용자는 여전히 진입 링크가 없다.** 헤더 primary nav 에 넣을지, 마이페이지 드롭다운에 넣을지는 정보구조 결정이라 임의로 바꾸지 않았다 |
| P1 | 하단 탭바 1급 승격 여부 | My World 가 "메인 사업" 급이면 `더보기` 안이 아니라 탭 하나를 받아야 한다. 현재 탭 5개(홈·인사이트·AI도구·게임·더보기) 중 무엇을 내릴지가 제품 결정 |
| P1 | `AccountMenu` 연결 | 프로필/레벨/EXP 를 보여주는 메뉴에서 "내 세계" 로 이어지는 것이 자연스럽다. 다만 이 컴포넌트는 `router.push` 기반의 큰 공용 컴포넌트라 회귀 위험이 있어 손대지 않았다 |

## P1 — 브랜드 버튼의 대비가 WCAG AA 미달 (사이트 전역)

### 실측

`#F9954E` 배경 + 흰 글자 = **2.23 : 1** (AA 일반 텍스트 기준 4.5 미달, 큰 텍스트 3.0 도 미달)

- `bg-[#F9954E]` 사용처: **285곳** (전 사이트)
- `hover:bg-[#E8832E]` = 약 3.2 : 1 — 역시 미달

### 이번에 한 것

**My World 안의 채워진 오렌지 버튼만** AA 통과 색으로 바꿨다(같은 따뜻한 테라코타 계열 유지).

| 용도 | 이전 | 이후 | 흰 글자 대비 |
| --- | --- | --- | --- |
| 채워진 CTA 배경 | `#F9954E` | `#AD5B18` | 2.23 → **4.92** |
| 위 버튼 hover | `#f0862f`/`#E8832E` | `#8F4A12` | — |
| 크림 배경 위 오렌지 텍스트 | `#E07C2E` | `#9A4E14` | 2.96 → **6.04** |

My World 텍스트 54개 실측 결과 **AA 미달 0개**(최저 4.51)로 정리됐다.

### 남은 것

사이트 전역 285곳을 같은 기준으로 바꾸려면 브랜드 컬러 결정이 필요하다.
**권장**: `#F9954E` 는 장식·면(대비 요구 없음)에 유지하고, **텍스트를 얹는 버튼**만
`#AD5B18` 같은 딥 톤을 쓰는 2단 토큰 체계. 전역 변경은 이 트랙 범위 밖.

## P2 — 전역 하단 여백 `lg:pb-[200px]`

`components/layout/LayoutClient.tsx:100`

```
<main className="flex-grow w-full pt-[100px] pb-[80px] lg:pb-[200px] xl:px-[260px] px-6 relative z-0">
```

lg 이상에서 콘텐츠와 footer 사이에 **200px 빈 공간**이 생긴다. 광고 레일이 footer 를 침범하지 않게
두는 여유로 보이지만, 짧은 페이지에서는 화면이 비어 보인다.

### 이번에 한 것

**My World 에서만** `lg:-mb-[120px]` 로 일부를 되돌렸다(다른 페이지 영향 0).
실측: gapToFooter 200px → **80px**, 12 viewport 전부에서 footer 침범·겹침 0.

### 남은 것

전역 값을 줄이려면 광고 레일 위치(`fixed left-6` / `right-[68px]`, 높이 662px)와
footer 충돌을 전 페이지에서 재검증해야 한다. 전역 변경은 하지 않았다.

## 확인했고 문제 없던 연결부

| 대상 | 결과 |
| --- | --- |
| 전역 header | My World 에서 겹침·가림 0 (12 viewport 실측) |
| 하단 모바일 nav | 실제로 가려진 인터랙티브 요소 **0개**(`elementFromPoint` 기준). 320~820px 에서 bounding box 는 겹치지만 스크롤로 도달 가능하며 페이지 하단 기준 영구 가림 없음 |
| 광고 레일(≥1280) | `xl:px-[260px]` 가 자리를 비워두므로 My World 콘텐츠(최대 1400px)와 충돌 0 |
| footer | 침범 0, gapToFooter 80px 로 일정 |
| 공통 toast/dialog | My World 는 자체 `role="dialog"` 만 쓰고 공통 toast 를 건드리지 않는다 |
| `AccountMenu` 의 죽은 미션 UI | **되살리지 않았다**(지시에 따라 그대로 둠) |

# Production 칭호 현황 — 읽기 전용 집계

도구 `scripts/audit-title-shape.mjs` · 실행 2026-07-27 · 기준 프로젝트 `dori-ai-0130`

> **집계 수치만 기록한다.** UID·email·닉네임·칭호 실제 문자열·개별 문서 원문은
> 스크립트가 출력하지 않으며 이 문서에도 없다. 임시 파일도 만들지 않았다(표준출력만).

## 접근 경로와 안전성

| 항목 | 값 |
|---|---|
| 인증 | 기존에 사용 중인 서비스 계정(백업 도구와 동일 경로) — **새 credential 탐색·발급 없음** |
| Firebase CLI | 인증 유효(`dori-ai-0130` 접근 가능) — 이번 집계에는 Admin SDK 사용 |
| 조회 방식 | `users` 컬렉션 1회 `.select("title","ownedItems","titleMode","titleId","customTitle")` — **필요한 필드만** |
| 반복 스캔 | 없음(1회) |
| **Firestore 쓰기** | **0건** — 스크립트에 `set/update/delete/create/batch/bulkWriter` 호출이 **하나도 없다**(정적 확인). 검출된 `.set(` 4건은 전부 in-memory `Map.set` |
| 임시파일 | 생성하지 않음 |

## 집계 결과

**조회 성공: 예** (아래 0 은 전부 "조회는 됐고 해당 문서가 없다"는 뜻이다)

| # | 항목 | 개수 |
|---|---|---|
| 1 | 전체 `users` 문서 수 | **7** |
| 2 | legacy `title` 이 비어 있지 않은 문서 | **1** |
| 3 | 상점 title 문자열과 **정확히 일치** | **1** |
| 4 | └ 해당 `title::<id>` 를 **실제 보유** | **1** |
| 5 | └ 일치하지만 **미보유**(복제 추정) | **0** |
| 6 | 상점과 불일치하는 **커스텀** title | **0** |
| 7 | `title` 타입이 문자열이 아닌 손상 문서 | **0** |
| 8 | `title` 길이 24자 초과 문서 | **0** |
| 9 | `ownedItems` 타입이 잘못된 문서 | **0** |
| 10 | 신규 title 필드(`titleMode`/`titleId`/`customTitle`)가 이미 있는 문서 | **0** |
| 참고 | `ownedItems` 에 title 상품을 보유한 문서 | **1** |
| 참고 | `title` 이 빈 문자열 / 공백만 | **0 / 0** |
| 참고 | 대조에 사용한 상점 칭호 문자열 수 | 77 (ko+en 표기) |

## 이 수치가 설계에 주는 의미

1. **커스텀 칭호 사용자가 0명이다.** → 자유 입력을 분리해도 **깨지는 기존 사용자가 없다.**
2. **미보유 복제가 0건이다.** → 소급 정정(회수) 대상이 없다. 데이터 마이그레이션 필요 없음.
3. **정상 구매자 1명은 실제로 보유 중이다.** → lazy resolver 규칙 ③(legacy + 보유 → catalog 로 해석)만으로
   그 사용자의 유료 효과가 **그대로 유지**된다. write-back 불필요.
4. **손상 데이터·타입 오류·길이 초과가 전부 0이다.** → fail-safe 분기는 필요하지만 실제 발동 대상이 없다.
5. **신규 필드가 이미 있는 문서 0건** → 필드명 충돌 없음.

> ⚠️ 이 결과는 **오늘 시점 7개 문서** 기준이다. 사용자가 늘면 달라진다.
> 그래서 구현은 "지금 데이터가 깨끗하니 대충 해도 된다"가 아니라
> **손상·복제·초과를 전부 fail-safe 로 처리하는 resolver** 로 간다(§title-authority-contract).

## 재실행

```bash
node scripts/audit-title-shape.mjs
```

인증이 없거나 키를 찾을 수 없으면 `UNAVAILABLE` 로 종료하며, 조회 실패는 `SCAN FAILED` 로
**0 과 구분해서** 보고한다(개수 0 을 스캔 실패로 오독하지 않도록).

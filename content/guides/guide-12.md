## 들어가며: 결론부터 말하면, 대부분은 무료로 됩니다

"AI 쓰려면 월 2만 원씩 내야 하나요?"

개인이 하는 일 기준으로는 **대체로 안 내도 됩니다.** 글쓰기, 문서 요약, 검색, 코딩, 이미지 생성, 심지어 음악 만들기까지 무료 등급으로 웬만큼 커버됩니다.

다만 조건이 있습니다. **무료 AI는 종류마다 한도 구조가 완전히 다릅니다.** 이걸 모르고 하나만 붙잡고 쓰다가 "한도 다 썼습니다"를 만나면 "역시 무료는 안 되는구나" 하고 결제하게 됩니다. 구조를 알면 결제 시점이 훨씬 뒤로 밀립니다.

이 글은 [AI 도구 모음](/ai-tools)에 정리해 둔 무료 AI 12종을 기준으로, **한도가 어떻게 다르고 무엇에 뭘 써야 하는지** 정리한 것입니다.

> ⚠️ 무료 한도는 각 서비스가 수시로 바꿉니다. 이 글은 **한도의 성격**(무제한급인지, 하루 단위인지, 몇 시간마다 리셋되는지)을 기준으로 썼습니다. 정확한 횟수는 각 서비스의 공식 요금제 페이지에서 확인하세요.

---

## 1. 무료 AI는 세 가지 유형으로 나뉜다

한도가 "얼마나 주느냐"보다 **"어떤 방식으로 주느냐"**가 실사용에서 훨씬 중요합니다.

### 유형 A — 사실상 무제한형

한도를 거의 신경 쓰지 않고 쓸 수 있는 쪽입니다.

- **DeepSeek** — 웹 채팅에 사실상 사용 한도가 없습니다. 수학·코딩 추론이 유료 모델급입니다
- **Google AI Studio** — 하루 요청 한도가 무료 서비스 중 가장 넉넉하고, **무료 API 키까지 발급**됩니다
- **Perplexity** — 기본 검색은 거의 무제한이고, 고급 검색만 하루 몇 회로 제한됩니다

이 셋은 "한도 걱정 없이 일단 던져보는" 용도로 씁니다.

### 유형 B — 한도형 (리셋 주기가 관건)

최신 모델을 정해진 양만큼 주는 쪽입니다. **중요한 건 총량이 아니라 리셋 주기입니다.**

- **ChatGPT 무료** — 최신 모델을 하루 정해진 횟수까지. 한도를 다 써도 **경량 모델로 자동 전환돼 대화가 끊기지 않습니다**
- **Claude 무료** — 한도가 하루 단위가 아니라 **몇 시간 주기로 다시 채워집니다.** 몰아 쓰면 금방 소진되지만, 나눠 쓰면 하루 종일 쓸 수 있습니다

이 차이가 실사용에서 큽니다. Claude는 "오전에 한 번, 오후에 한 번" 식으로 쓰면 유료 없이도 꽤 버팁니다. 반대로 한 번에 몰아 쓰면 30분 만에 막힙니다.

### 유형 C — 기능 제한형

쓸 수는 있는데 **속도나 기능에 차등**을 두는 쪽입니다.

- **Microsoft Copilot** — 이미지 생성에 하루치 고속 크레딧을 주고, 다 쓰면 **속도만 느려질 뿐 계속 생성됩니다**
- **Canva Magic Studio** — 디자인 도구 안에서 AI 기능을 일정량 제공합니다
- **Leonardo.Ai** — 이미지 생성에 하루 크레딧이 충전됩니다

"막히는" 게 아니라 "느려지는" 구조라, 급하지 않으면 계속 쓸 수 있습니다.

## 2. 하려는 일별로 무엇을 쓰나

무료 AI를 하나만 고르려 하면 실패합니다. **일마다 강한 게 다릅니다.**

| 하려는 일 | 무료로 쓸 것 | 이유 |
|---|---|---|
| 보고서·글쓰기 | **Claude** | 긴 문서 이해와 문장 품질이 가장 낫습니다 |
| 검색·사실 확인 | **Perplexity** | 답변마다 출처 링크가 붙어 그대로 인용할 수 있습니다 |
| 코딩·수학 | **DeepSeek** | 추론 성능이 유료급인데 한도가 사실상 없습니다 |
| 일상 잡무·파일 처리 | **ChatGPT 무료** | 무료 플랜에도 이미지 인식·파일 업로드·웹 검색이 열려 있습니다 |
| 이미지 생성 | **Copilot** / **Leonardo.Ai** | 크레딧을 다 써도 느리게나마 계속 됩니다 |
| 음악 만들기 | **Suno** | 무료 등급으로 곡 생성이 가능합니다 |
| 발표자료·디자인 | **Canva Magic Studio** | 디자인 작업 흐름 안에 AI가 들어가 있습니다 |
| 개인 프로젝트에 AI 붙이기 | **Google AI Studio** | **무료 API 키**가 나와 코드에 바로 연결됩니다 |
| 새 모델 체험 | **Hugging Face Spaces** | 남이 올린 모델 데모를 설치 없이 돌려봅니다 |
| 코드 실행 환경 | **Google Colab** | 브라우저에서 GPU를 무료로 씁니다 |

전체 목록과 각 도구의 장단점은 [AI 도구 모음](/ai-tools)에서 볼 수 있습니다.

### 고르기 전에 알아둘 단점

무료 AI 추천 글은 장점만 나열하는 경우가 많습니다. **실제로 쓰다 보면 걸리는 지점**을 함께 적어 둡니다.

| 도구 | 알아둘 점 |
|---|---|
| Google AI Studio | 입력 데이터가 모델 개선에 쓰일 수 있습니다(무료 등급). 인터페이스가 개발자 중심이라 처음엔 낯섭니다 |
| ChatGPT 무료 | 최신 모델 무료 횟수가 하루 기준으로 빠듯합니다. 혼잡한 시간대엔 응답이 느려집니다 |
| Claude 무료 | 한 번에 몰아 쓰면 한도가 금방 소진됩니다. 이미지 생성은 지원하지 않습니다 |
| Perplexity 무료 | 고급 검색은 하루 몇 회로 제한됩니다. 긴 창작 글쓰기에는 맞지 않습니다 |
| DeepSeek | 데이터가 중국 서버에 저장돼 민감 정보에는 부적합합니다. 정치·역사 등 일부 주제에 답변 제약이 있습니다 |

이 표를 보고 나면 왜 **하나만 쓰면 안 되는지**가 분명해집니다. 각 도구가 막히는 지점이 서로 다르기 때문에, 조합해서 쓰면 대부분 상쇄됩니다.

## 3. 무료로 하루를 버티는 실전 조합

한도에 걸려도 작업이 안 끊기게 하는 방법은 **리셋 주기가 다른 도구를 섞는 것**입니다.

**아침 — 무거운 작업 먼저**
Claude로 긴 문서 검토나 보고서 초안을 잡습니다. 한도가 가장 아까운 작업을 가장 좋은 모델에 먼저 씁니다.

**낮 — 한도 없는 쪽으로 이동**
Claude 한도가 줄어들면 DeepSeek(코딩·계산)과 Perplexity(자료 조사)로 옮깁니다. 둘 다 한도 걱정이 거의 없습니다.

**오후 — Claude 한도 리셋**
몇 시간이 지나면 Claude 한도가 다시 채워집니다. 아침에 잡아둔 초안을 다듬습니다.

**아무 때나 — 잡무는 ChatGPT 무료**
파일 정리, 번역, 간단한 질문은 ChatGPT 무료로 넘깁니다. 한도를 넘겨도 경량 모델로 계속 돌아가니 막히지 않습니다.

이 정도만 나눠도 개인 작업은 대부분 유료 없이 굴러갑니다.

## 4. 무료의 진짜 비용 — 알고 쓰세요

공짜라고 대가가 없는 건 아닙니다. **돈이 아닌 것으로 냅니다.**

### ① 입력한 내용이 학습에 쓰일 수 있습니다

무료 등급에서는 대화 내용이 모델 개선에 사용될 수 있습니다. Google AI Studio 무료 등급도 마찬가지입니다.

→ **회사 내부 문서, 고객 정보, 미공개 코드는 넣지 마세요.** 이건 요금제 문제가 아니라 원칙입니다.

### ② 데이터가 어디에 저장되는지 다릅니다

DeepSeek은 성능이 좋고 무료지만 **데이터가 중국 서버에 저장됩니다.** 개인 학습용으로는 훌륭하지만 업무 자료에는 부적합합니다. 정치·역사 등 일부 주제에는 답변 제약도 있습니다.

→ 무료 AI를 고를 때 성능만 보지 말고 **어디에 저장되는지**를 함께 보세요.

### ③ 한도를 예측할 수 없습니다

무료 한도는 공지 없이 바뀝니다. 어제 되던 게 오늘 안 될 수 있습니다.

→ 마감이 걸린 작업을 무료 한도에 의존하지 마세요. 그때가 유료를 쓸 때입니다.

## 5. 그럼 언제 돈을 내야 하나

유료로 넘어갈 시점은 사용량이 아니라 **성격**으로 판단하는 게 정확합니다.

**아직 무료로 버텨도 되는 경우**
- 하루 몇 번씩 산발적으로 씁니다
- 막히면 다른 도구로 옮겨도 괜찮습니다
- 다루는 내용이 공개돼도 상관없습니다

**유료로 넘어갈 때**
- **마감이 걸립니다.** 한도에 막혀 멈추는 비용이 구독료보다 큽니다
- **민감한 자료를 다룹니다.** 유료 등급은 대체로 학습 제외 옵션이 있습니다
- **서비스에 AI를 붙입니다.** 이건 구독이 아니라 **API 종량 과금**의 영역입니다

마지막 경우가 중요합니다. 챗봇이나 자동화를 만들어 사용자에게 제공하려면 월 구독이 아니라 **쓴 만큼 내는 API 요금**을 계산해야 합니다. 그 구조는 [AI API 요금 구조 완전 해부](/insight/article/guide-11)에 정리해 뒀고, 실제 금액은 [AI 모델 가격 비교 · 비용 계산기](/ai-models)에서 바로 계산할 수 있습니다.

의외로 저렴합니다. 소규모 서비스라면 **월 몇 달러 수준**에서 시작하는 경우가 많습니다.

## 마무리

정리하면 이렇습니다.

- 무료 AI는 **사실상 무제한형 / 한도형 / 기능 제한형** 셋으로 나뉩니다
- **총량보다 리셋 주기가 중요합니다.** Claude는 몇 시간마다 채워지고, ChatGPT는 한도 후에도 경량 모델로 이어집니다
- **하나만 쓰지 말고 일마다 나누세요.** 글은 Claude, 검색은 Perplexity, 코딩은 DeepSeek
- 공짜의 대가는 **데이터**입니다. 민감한 자료는 넣지 마세요
- 유료 전환은 사용량이 아니라 **마감·민감도·서비스화** 여부로 판단합니다

무엇부터 써볼지 모르겠다면 **Google AI Studio**부터 열어보세요. 한도가 가장 넉넉하고 무료 API 키까지 나옵니다.

# AI만학도 유튜브 채널 배너 — 작업 지시서

배경: 3모니터 작업 데스크 유화(크림·베이지 톤, 4:3)
오버레이: `banner-overlay-a.svg` (라이트) / `banner-overlay-b.svg` (다크)

---

## ⚠️ 먼저 알아야 할 것 — "하단"에 글씨를 깔면 안 된다

유튜브 배너는 **기기마다 보이는 범위가 다르다.**

| 기기 | 실제로 보이는 영역 |
|---|---|
| TV | 2048 × 1152 (전체) |
| 데스크톱 | 1546 × 423 (중앙 가로띠) |
| 모바일 | 1546 × 423 |
| **모든 기기 공통 = 안전영역** | **1235 × 338 (정중앙)** |

캔버스 진짜 바닥에 채널명을 깔면 **모바일·데스크톱에서 통째로 잘린다.**
그래서 이 설계는 "하단 밴드"의 **인상은 유지하되**, 밴드를 **안전영역의 아래쪽**에 놓았다.
보기에는 책상 위에 얹힌 띠지만, 모든 기기에서 살아남는다.

---

## 규격

- **캔버스**: 2048 × 1152 (16:9)
- **파일**: JPG 또는 PNG, **6MB 이하**
- **안전영역**: x `406`–`1641`, y `407`–`745`
- **데스크톱 표시영역**: x `251`–`1797`, y `364`–`787`

## 배경 크롭

원본이 4:3이라 16:9로 **위아래를 잘라야 한다.**

- 상단(벽·시계 위 여백)에서 많이, 하단(책상 앞쪽)에서 조금 — 대략 **7 : 3**
- **기준선**: 키보드가 놓인 책상 면이 **y 548 ~ 742** 구간에 오도록 맞춘다. 거기가 텍스트 자리다.
- SVG에서는 `<image>` 에 `preserveAspectRatio="xMidYMid slice"` 가 걸려 있어 자동으로 잘린다.
  세로 위치만 미세 조정하면 된다.

## 텍스트 배치 (2048 × 1152 절대좌표)

```
밴드    : x 0 → 2048 (전체 너비), y 548 → 742 (높이 194)
          위아래 가장자리는 투명으로 페이드 — 유화 위에 판때기처럼 얹히지 않게
채널명  : x 470,  baseline y 652,  100px,  Weight 800,  자간 -2
태그라인 : x 474,  baseline y 710,   40px,  Weight 500,  자간 -0.5
```

**실측 검증 결과** (텍스트 바운딩 박스 x 469–1083, y 576–715)

| 방향 | 안전영역까지 여백 |
|---|---|
| 좌 | 63px |
| 우 | 558px |
| 상 | 169px |
| 하 | 30px |

→ 모든 기기에서 잘리지 않는다. **좌표를 바꿀 때는 이 여백을 다시 확인할 것.**
특히 **하단 여백이 30px밖에 없다.** 태그라인을 더 내리거나 키우면 모바일에서 잘린다.

## 색

**A안 · 라이트** — 그림에 녹아듦, 차분함
| 요소 | 값 |
|---|---|
| 밴드 | `#F7F1E3` 88% |
| 채널명 | `#1C1C1C` |
| 태그라인 | `#4A4438` |
| 포인트(AI) | `#D99A2B` |

**B안 · 다크** ← **추천**
| 요소 | 값 |
|---|---|
| 밴드 | `#14213D` 82% |
| 채널명 | `#F5EFE0` |
| 태그라인 | `#C9C2B4` |
| 포인트(AI) | `#E8A33D` |

B안을 추천하는 이유: 1화 대본에 정한 그림체 규칙이 *"흑백 다큐 톤 + 앰버 포인트 1개"* 였다.
B안으로 가면 **배너·썸네일·영상이 한 채널처럼** 보인다. 밴드의 딥네이비는 그림 속 모니터 베젤 색이고,
앰버는 키보드 노란 키캡 색이라 둘 다 그림에서 뽑아온 색이다.

## 폰트 (무료 상업용)

- 채널명: **Pretendard ExtraBold(800)**
- 태그라인: **Pretendard Medium(500)**
- 대안(더 조용한 톤): 리디바탕 Bold

> SVG의 `font-family` 에 폴백을 걸어뒀다. **Pretendard가 설치돼 있지 않으면 다른 글꼴로 대체되어
> 자폭·굵기가 달라진다.** 최종 출력 전에 Pretendard 설치를 확인할 것.

## 카피

**채널명**: `AI만학도` — `AI` 만 앰버, `만학도` 는 본문색

**태그라인**: `늦게 시작해서, 직접 만들어 봅니다`

다른 후보:
- `내가 먼저 헤매고, 그대로 알려드립니다`
- `AI로 만들다가 망한 기록` — 강하지만 배너는 오래 걸어두는 간판이라 특정 시리즈에 묶이면
  나중에 발목을 잡는다. **썸네일 카피로 쓰는 편이 낫다.**

## 작업 순서

1. `banner-overlay-b.svg` 를 연다 (일러스트레이터 · Figma · Inkscape · 브라우저 아무거나)
2. `<image id="bg">` 의 `xlink:href` 에 유화 원본 경로를 넣는다
3. 배경 세로 위치를 조정해 **책상 면이 y 548~742 에 오게** 맞춘다
4. `<g id="guides">` 의 `display="inline"` → `display="none"` 으로 바꾼다 (또는 통째로 삭제)
5. 2048 × 1152 PNG/JPG로 내보낸다 (6MB 이하)
6. 유튜브 스튜디오 → 맞춤설정 → 브랜딩 → 배너 이미지 업로드
7. **업로드 화면의 미리보기에서 TV / 데스크톱 / 모바일 세 가지를 반드시 확인**한다

## 원본 이미지 주의점

모니터 화면 속 한글이 뭉개져 있다(AI 생성 흔적). 배너 크기에서는 티가 안 나지만,
**확대하거나 화면 부분만 크롭해 쓰면 드러난다.** 지금 구도 그대로 쓰면 문제없다.

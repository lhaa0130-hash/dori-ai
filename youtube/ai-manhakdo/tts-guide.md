## 결론 — 브루(Vrew) 하나로 시작합니다

편집 · 자동자막 · **내 목소리 복제**가 한 프로그램에서 끝납니다.
1화 나레이션이 2,312자라 **무료 한도 안에서 커버됩니다.** 처음부터 결제할 이유가 없습니다.

| 단계 | 도구 | 비용 |
|---|---|---|
| 목소리 복제 (약 10분 녹음) | 브루 "AI 내 목소리" | 무료 |
| 대본 → 내 목소리 나레이션 | 브루 | 무료 크레딧 내 |
| 자동 자막 | 브루 | 무료 크레딧 내 |
| 컷 편집 · 화면 연출 | 브루 (부족하면 캡컷) | 무료 |

## 1. 브루 "AI 내 목소리"

- 약 **10분 녹음** → 내 목소리 AI 생성 → 이후 텍스트를 넣으면 내 목소리로 읽어줌
- 무료 플랜: 매월 1일 **200크레딧** 충전 (이월 안 됨)
- 환산: **1크레딧 = AI 목소리 100자** = 음성분석 1분 = 번역 300자
- → 월 약 **10,000~20,000자** (자료마다 수치가 다름 / 1화 2,312자는 여유롭게 커버)
- 제약: **무료는 목소리 1개만.** 다른 목소리를 만들려면 기존 것을 지워야 함

## 2. 워터마크 — 무료로 어디까지 되나

| 상황 | 워터마크 |
|---|---|
| 일반 컷편집 · 자동자막 · 영상 내보내기 | **안 붙음** |
| **AI 이미지 · AI 비디오** 등 AI 생성 기능 결과물 | **붙음** |
| 워터마크 완전 제거 | 유료 (Light 약 ₩9,900/월 ~ Standard 약 ₩17,900/월) |

**무료 우회로**: 편집 화면에서 워터마크 클릭 → 삭제 아이콘 → **'출처 표기' 신청서 제출**
→ 한 달간 워터마크 없이 사용, 한 달 뒤 재신청.

**→ 실전 대응**: 1화는 실제 아카이브 사진·영상이 주인공이라 **AI 이미지를 거의 안 씁니다.**
그러니 무료 플랜에서도 워터마크 문제가 사실상 없습니다. (대본의 그림체 규칙 참고)

## 3. 갈아탈 때 후보 — TTS 비교

지금 당장 필요하진 않습니다. 브루 품질이 아쉬워지면 그때 봅니다.

| 서비스 | 한국어 | 내 목소리 복제 | 필요 녹음 | 무료 한도 | API |
|---|---|---|---|---|---|
| **브루 (Vrew)** | 좋음 | ✅ 약 10분 | 10분 | 월 200크레딧 | ✕ (앱 내장) |
| **ElevenLabs** | 매우 좋음 | ✅ Instant 1~3분 / Pro 30분+ | 1분~ | 월 소량 | ✅ |
| Supertone Play | 매우 좋음 | ✅ | 수 분 | 제한적 | ✅ |
| Typecast | 좋음 | ✅ | 수 분 | 제한적 | ✅ |
| OpenAI TTS | 보통 | ✕ (기본 보이스만) | — | 종량제 | ✅ |

**업그레이드 경로**: 롱폼 나레이션 품질이 채널의 승부처가 되는 시점에 **ElevenLabs**로.
Instant Clone(1~3분)으로 먼저 싸게 테스트해보고, 만족하면 Professional Clone(30분+)으로 올리는 순서.
이 판단은 이 repo에 이미 들어있는 선택과도 같습니다 —
`lib/illo/modelMatrix.ts:104` (`tts: elevenlabs / eleven_multilingual_v2 — 성우·나레이션 최상`),
`lib/illo/apiCatalog.ts:155-172` (ElevenLabs를 `pick`으로, API 키 발급 절차까지 정리됨).

## 4. 편집 도구 — 브루 vs 캡컷

| | 브루 | 캡컷 |
|---|---|---|
| 한국어 자동자막 | ◎ 최상 | ○ |
| 대본 → 영상 자동 생성 | ◎ | △ |
| 내 목소리 복제 | ◎ 있음 | ✕ |
| 컷 · 트랜지션 · 효과 | ○ | ◎ |
| 무료 워터마크 | AI 생성 기능 사용 시 | 일부 템플릿·효과 사용 시 |

**추천 워크플로우**

```
ep01-ai-history.tts.txt
   ↓ 붙여넣기
브루 — 내 목소리 TTS + 자동자막 + 초벌 컷
   ↓ (필요할 때만)
캡컷 — 화면 연출·트랜지션 보강
   ↓
유튜브 업로드
```

롱폼 나레이션 채널은 **브루 하나로 끝나는 경우가 많습니다.** 캡컷은 필요해지면 그때 붙이세요.

## 5. 목소리 녹음 가이드

**녹음용 대본은 따로 만들지 않습니다.** `ep01-ai-history.tts.txt` 를 그대로 낭독하세요.
목소리 샘플 확보 + 1화 육성 버전 확보가 한 번에 됩니다.

**환경**
- 조용한 방. 밤이 낫습니다. 냉장고·에어컨·시계 초침 끄기
- 벽 반사가 목소리를 뭉갭니다 → 커튼을 치거나, 이불을 뒤집어쓰고 녹음해도 효과가 큽니다
- 옷장 안이 의외로 최고의 녹음실입니다

**장비**
- USB 콘덴서 마이크 (5~10만 원대면 충분)
- 팝필터 — 없으면 마이크를 입 정면이 아니라 **살짝 비껴서** 두세요. 'ㅍ' 'ㅂ' 소리 터짐 방지

**자세**
- 입–마이크 거리 **15cm 고정.** 왔다 갔다 하면 복제 품질이 떨어집니다
- 톤과 속도를 **일정하게.** 감정을 넣기보다 평탄하게 읽는 편이 학습에 유리합니다
- **한 번에 몰아서** 녹음. 날을 나누면 컨디션 차이가 그대로 학습됩니다

**후처리**
- 잡음 제거, 3초 이상 긴 무음 잘라내기
- 실수한 문장은 지우기 (틀린 발음까지 학습됩니다)

## 6. 주의사항

- **무료는 목소리 1개.** 신중하게 한 번에 잘 녹음하세요
- **AI 목소리 상업적 이용(유튜브 수익화)** 은 서비스마다 약관이 다릅니다. 반드시 확인
- **유튜브 AI 콘텐츠 표시 정책** — 합성 음성 사용 시 업로드할 때 고지해야 할 수 있습니다
  → 1화 설명란에 이미 문구를 넣어뒀습니다: *"이 영상의 나레이션은 제 목소리를 학습시킨 AI 음성으로 제작했습니다."*
- 본인 목소리만 복제하세요. 타인 목소리는 동의 없이 쓰면 문제가 됩니다

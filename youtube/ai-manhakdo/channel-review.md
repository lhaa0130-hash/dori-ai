## 1. 배너 ★ 최우선

**어디서** 맞춤설정 → 브랜딩 → 배너 이미지 → **미리보기 3종**

| | |
|---|---|
| **본다** | TV / 데스크톱 / 휴대기기 미리보기에서 `AI만학도` 와 태그라인 |
| **합격** | 세 화면 **모두**에서 두 줄이 온전히 보인다. 글자가 화면 밖으로 나가지 않는다 |
| **불합격** | 모바일·데스크톱에서 태그라인 아랫부분이 잘린다 |

**왜 여기가 제일 위험한가** — 유튜브 배너는 기기마다 보이는 범위가 다르다.

| 기기 | 보이는 영역 |
|---|---|
| TV | 2048 × 1152 (전체) |
| 데스크톱 · 모바일 | 1546 × 423 |
| **공통 안전영역** | **1235 × 338 (정중앙)** |

내가 만든 배너의 텍스트 실측 위치와 안전영역까지의 여백:

```
텍스트 바운딩박스 : x 469~1083,  y 576~715
안전영역          : x 406~1641,  y 407~745
여백  좌 63px · 우 558px · 상 169px · 하 30px
```

⚠️ **하단 여백이 30px뿐이다.** 계산상 안 잘리지만 가장 얇은 쪽이라, 실물 미리보기에서 여기부터 본다.
잘린다면 `banner-vector.svg` 의 태그라인 `y="710"` 을 `y="700"` 으로 올리고 다시 내보내면 된다.

근거: `banner-spec.md` · 파일: `_assets/banner-vector-2048x1152.png` (2048×1152, 3.01MB)

## 검토를 받으려면

### 스크린샷으로 보낼 때

| # | 화면 | 캡처 조건 |
|---|---|---|
| 1 | 맞춤설정 → **브랜딩** | **미리보기 3종(TV/데스크톱/모바일)이 한 화면에 보이게** ← 제일 중요 |
| 2 | 맞춤설정 → **프로필** | 설명 전문이 보이게 스크롤 (길면 2장) |
| 3 | 맞춤설정 → **레이아웃** | 섹션 목록 전체 |
| 4 | 설정 → **채널 → 고급설정** | 국가·키워드·이메일 |
| 5 | 설정 → **업로드 기본값** | 공개범위·카테고리 |

한 장씩 보내도 되고 한 번에 보내도 된다. 1번만으로도 검토를 시작할 수 있다.

### Chrome Control 이 연결됐다면

브라우저 제어 도구가 이 세션에 들어온 뒤, 위 1→5 순서로 화면을 열어 같은 기준으로 판정한다.
**주의**: 이 세션은 클라우드 컨테이너에서 실행된다. 사용자 PC 의 크롬과 물리적으로 다른 기계이므로
커넥터를 켜도 닿지 않을 수 있다. 도구가 실제로 목록에 들어왔는지 먼저 확인해야 한다.

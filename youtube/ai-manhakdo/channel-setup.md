# AI만학도 — 채널 개설 · 초기 세팅 체크리스트

기존 `illo` 채널은 dori-ai.com 브랜드용으로 남기고, **AI만학도는 별도 브랜드 계정**으로 만든다.

---

## ⚠️ 0. 매번 확인 — 지금 어느 채널인가

채널이 둘이 되면 **`illo` 에 잘못 올리는 사고**가 가장 흔하다.

- 프로필 사진 → **계정 전환** → `AI만학도` 선택
- YouTube Studio **좌측 상단 채널명**이 `AI만학도` 인지 눈으로 확인
- 업로드·설정을 만지기 전에 매번 본다

> ⚠️ 새 채널이라 **수익화 조건을 처음부터 채워야 한다** (구독 1,000명 + 시청 4,000시간).
> `illo` 의 실적은 넘어오지 않고, 나중에 합칠 수도 없다.

---

## 1. 채널 개설

- [ ] `youtube.com/channel_switcher` 접속 (또는 프로필 → 설정 → 계정 → **채널 추가 또는 관리**)
- [ ] **채널 만들기** 클릭
- [ ] 이름 `AI만학도` 입력 → **만들기**
- [ ] 브랜드 계정인지 확인 — 설정에 **'관리자 추가 또는 삭제'** 항목이 보이면 맞음

브랜드 계정이라 개인 구글 계정 이름·이메일이 노출되지 않고, 나중에 관리자를 추가하거나 소유권을 넘길 수 있다.

## 2. 기본 정보

**맞춤설정 → 기본 정보**

- [ ] 채널명: `AI만학도`
- [ ] 핸들 — 선점됐을 수 있으니 후보를 순서대로 시도
      `@ai-manhakdo` → `@aimanhakdo` → `@ai만학도`
- [ ] 국가: 대한민국
- [ ] 연락처 이메일 (비즈니스 문의용)

**채널 설명** — 검색에 반영되므로 키워드를 심는다. 아래를 그대로 붙여넣어도 된다.

```
AI를 늦게 시작한 사람이, 먼저 공부하고 알려드리는 채널입니다.

전문가가 아닙니다. 저도 한참 늦게 시작했습니다.
그래서 무료로 쓸 수 있는 AI 사이트부터 하나씩 직접 써보고,
헤맨 부분까지 그대로 알려드립니다.

· AI 입문 · 무료 AI 도구 사용법 · 챗GPT 활용
· 프롬프트 기초 · AI로 실제로 만들어보기

돈 드는 이야기는 최대한 나중에 합니다.
```

- [ ] **채널 키워드** (설정 → 채널 → 기본 정보)
      `AI입문, 무료AI, 챗GPT, AI배우기, AI초보, 프롬프트, AI도구, 인공지능강의`

## 3. 브랜딩

**맞춤설정 → 브랜딩**

- [ ] **배너 이미지** — `_assets/banner-vector-2048x1152.png` 업로드
      (2048×1152 · 3.1MB · 유튜브 제한 6MB 이내)
- [ ] 업로드 후 **미리보기 3종을 반드시 확인**: TV / 데스크톱 / 휴대기기
      → 세 화면 모두에서 `AI만학도` 와 태그라인이 안 잘리는지
      (규격·안전영역 근거는 `banner-spec.md` 참고)
- [ ] **프로필 사진** — 800×800 권장, **원형으로 잘리므로** 가장자리에 중요한 요소를 두지 말 것
- [ ] **동영상 워터마크** — 구독 유도 아이콘. 표시 시간은 **전체 동영상** 권장

## 4. 레이아웃

**맞춤설정 → 레이아웃**

- [ ] 비구독자용 **채널 예고편** — 1화를 그대로 걸어도 된다
- [ ] 재방문 구독자용 **추천 동영상** — 최신 업로드

- [ ] **섹션·재생목록은 영상이 쌓인 뒤에 만든다**

> ⚠️ **빈 섹션을 미리 만들지 말 것.** 콘텐츠 없는 빈 칸은 '준비 중인 채널' 인상을 준다.
> 이 repo의 `lib/publicFlags.ts` 에 똑같은 이유로 사이트 `/video` 섹션을 내렸던 기록이 남아 있다.
> 같은 실수를 유튜브에서 반복하지 않는다.

## 5. 업로드 기본값

**설정 → 업로드 기본값**

- [ ] 기본 카테고리: **과학기술** 또는 **교육**
- [ ] 기본 공개 범위: **비공개** (실수로 미완성본이 공개되는 사고 방지)
- [ ] 기본 설명 템플릿:

```

──────────────
🔗 dori-ai.com
AI 도구 정리 · 인사이트 글

※ 이 영상의 나레이션은 제 목소리를 학습시킨 AI 음성으로 제작했습니다.
```

- [ ] **'변경된 콘텐츠' 고지** — 업로드 화면에서 AI 합성 음성 사용 여부를 묻는 항목에 체크
      (자세한 정책·주의사항은 `tts-guide.md` 참고)

## 6. 보안

- [ ] 소유 구글 계정에 **2단계 인증** 활성화

브랜드 계정이라도 **소유 구글 계정이 뚫리면 채널을 통째로 잃는다.** 채널이 커진 뒤에 하려면 늦다.

## 7. 1화 업로드 직전 최종 점검

제목·설명·태그·챕터 타임스탬프는 **이미 정리돼 있다 → `ep01-ai-history.md` 맨 아래 '업로드 메타' 참고.**

- [ ] 계정이 `AI만학도` 인가 (다시 확인)
- [ ] 썸네일 업로드 — 모바일 320px에서 글씨가 읽히는지
- [ ] 제목 — 후보 3개 중 선택
- [ ] 설명란에 **챕터 타임스탬프** 포함 (00:00 부터 시작해야 챕터가 생성됨)
- [ ] 태그 입력
- [ ] **AI 음성 고지** 체크
- [ ] 최종 검토 후 공개 — 평일 저녁 또는 주말 오전 권장
